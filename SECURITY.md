# Security Policy

## Reporting a Vulnerability

To report a security vulnerability in `mlautograd`, please e-mail
**engineers@swelabs.io** with the subject line `[SECURITY] mlautograd`.

Include:
- A description of the vulnerability and its potential impact.
- Reproduction steps or a minimal proof-of-concept.
- Any suggested mitigations if you have them.

We aim to acknowledge reports within 48 hours and provide a resolution timeline
within 7 business days.

Do **not** open a public GitHub issue for security vulnerabilities.
